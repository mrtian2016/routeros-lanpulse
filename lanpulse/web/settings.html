设置页已关闭

没有配置管理员密码，设置页处于关闭状态 —— 这是刻意的：不设默认密码，就不会有默认密码被扫到。
要启用，在 .env 里设置 ADMIN_PASSWORD 后重启容器：

ADMIN_PASSWORD=your-password
docker compose up -d

config.toml

保存前会先校验 TOML 语法，语法不过就不会动磁盘上的文件；保存时旧版本会存成 config.toml.bak。改完即时生效，只有监听端口这类启动项需要重启容器。
